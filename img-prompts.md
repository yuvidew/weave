# Weave — 5-Step Flow Image Prompts

Six companion prompts for a step-by-step Weave product carousel (square 1:1, written for DALL-E / ChatGPT / Gemini-style natural-language image generation): one cover/title slide plus five system-flow diagrams, one per step. Each prompt is fully self-contained — copy-paste any one on its own — and all six repeat the same style block so the set reads as one matching series.

Images 1–5 are **flowchart diagrams**, not UI screenshots — each shows the real technical pipeline behind that step as four connected boxes naming the actual pieces involved (Clerk, Groq, Pipedream, Inngest, the database), not a mockup of what's on screen.

**Source accuracy:** each flow diagram's four steps name the real pieces of the actual system, not invented ones:
- Image 1 → user submits credentials → Clerk verifies the session → `proxy.ts` wires Clerk's request context via `clerkMiddleware()` → `app/(root)/layout.tsx` checks `auth()` and grants access to the dashboard.
- Image 2 → user types a goal in `create-agent.tsx` → `app/api/agent/configure/route.ts` calls Groq to turn it into an agent config → the config is validated and saved via `db/schema.ts`'s `AgentConfig` table → the agent appears ready in "My Agents".
- Image 3 → user clicks Connect on a `PluginCard` → `lib/pipedream.ts` mints a Pipedream Connect token → the user authorizes the app via Pipedream's hosted OAuth flow → the tool is marked "Connected" (per-user, not per-agent).
- Image 4 → a schedule comes due or "Run now" is clicked (`app/api/agent/run/route.ts`) → an event is sent to Inngest → `inngest/functions.ts` (`ProcessScheduledAgent`/`ExecuteScheduleAgent`) picks it up and calls `lib/execute-agent.ts` → the agent calls its connected tools.
- Image 5 → the run finishes → its outcome is written to the `AgentRun` table (`db/schema.ts`) → fetched via `app/api/logs` → rendered in the Runs dashboard.

**Tip:** these are natural-language prompts, so wording alone won't guarantee pixel-identical style across six separate generations. For the tightest visual match:
- Generate all six in the same chat/session back-to-back rather than in separate sessions.
- Generate the cover (Image 0) first, then ask the tool to "generate the next one in the exact same style" for images 1–5 instead of pasting each prompt cold.
